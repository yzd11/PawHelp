# 配件与耗材

## 饮水机滤芯型号

MH-W20 使用 FT-20 滤芯，MH-W40 使用 FT-40 滤芯，MH-W60 使用 FT-60 滤芯。三种滤芯尺寸不同，不可混用。

## 猫砂盆耗材型号

MH-LP100 与 MH-LP50 使用 DC-1 除臭包，MH-LP200 使用 DC-2 大容量除臭包；BG-50 垃圾袋三款猫砂盆通用。

## 配件购买入口

原装滤芯、除臭包、剑麻替换柱等配件，可在 App「设备」页的「耗材商城」购买，也可在商城直接搜索配件型号下单。

## 第三方耗材与保修

使用非原装耗材不会影响设备的保修资格，但因第三方耗材导致的故障不在免费保修范围内，维修需另行收费。
